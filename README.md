# همراه‌پزشک — نمونه اولیه پایتون

## اجرا در ویندوز
1. Python 3.10 یا جدیدتر نصب باشد.
2. در پوشه پروژه ترمینال باز کنید.
3. اجرا کنید:

```bash
py -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
py app.py
```

4. در مرورگر باز کنید: http://127.0.0.1:5000

## امکانات موجود
- صفحه اصلی با چهار پزشک نمونه
- پروفایل اختصاصی پزشکان
- فرم متفاوت برای هر تخصص
- شرح حال آزاد و بارگذاری فایل
- غربالگری بسیار ابتدایی کلمات هشدار (بدون تشخیص پزشکی)
- ثبت درخواست در SQLite
- پنل نمایشی پزشک برای بررسی درخواست
- ایجاد کد نمایشی فقط پس از اقدام تأیید پزشک
- گفت‌وگوی ساده ذخیره‌شونده پس از تأیید

## محدودیت‌ها و الزامات پیش از استفاده واقعی
این پروژه صرفاً MVP آموزشی است. از آن برای مراقبت واقعی، تشخیص، نسخه‌نویسی یا ارسال نسخه به داروخانه استفاده نکنید.
- پنل پزشک و مسیرهای مدیریتی فعلاً احراز هویت ندارند.
- کد نسخه به سامانه داروخانه متصل نیست و صرفاً نمایشی است.
- چت بلادرنگ نیست.
- فایل‌ها و اطلاعات پزشکی رمزنگاری نشده‌اند.
- قبل از انتشار باید HTTPS، احراز هویت چندنقشی، کنترل دسترسی پرونده، رمزنگاری، ثبت رویداد، پشتیبان‌گیری، محدودیت نرخ، اعتبارسنجی فایل و سیاست حریم خصوصی پیاده‌سازی شود.
- تصمیم تشخیصی و درمانی و نسخه باید توسط پزشک دارای صلاحیت انجام شود.
- عکس پزشکان در این نسخه با آواتارهای نمادین جایگزین شده‌اند؛ می‌توانید تصاویر ساختگی مجاز را در قالب فایل محلی اضافه کنید.

## متغیر امنیتی
در `app.py` مقدار `app.secret_key` را پیش از هر استفاده واقعی با یک مقدار تصادفی امن جایگزین کنید.


## انتشار آزمایشی روی Render
1. پروژه را در یک مخزن GitHub جدید بارگذاری کنید.
2. در Render گزینه New > Blueprint را انتخاب و مخزن GitHub را متصل کنید.
3. فایل `render.yaml` به‌صورت خودکار سرویس وب را تنظیم می‌کند.
4. پس از Deploy، آدرس عمومی `.onrender.com` در داشبورد Render نمایش داده می‌شود.

توجه: پلن رایگان ممکن است پس از مدتی بی‌استفاده‌بودن به خواب برود و فایل‌های محلی/SQLite روی فضای موقت پایدار نیستند. برای داده واقعی پزشکی از این تنظیم استفاده نکنید؛ قبل از هر استفاده واقعی باید پایگاه داده و فضای فایل پایدار، کنترل دسترسی و الزامات امنیتی/حقوقی فراهم شود.
